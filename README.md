# CampusAI

CampusAI is an AI-powered academic assistant built using Python, Streamlit, Groq API, FAISS, and Sentence Transformers.

## Features

- AI Chat
- Chat with PDF
- PDF Summarization
- MCQ Generator
- Viva Question Generator

## Tech Stack

- Python
- Streamlit
- Groq API
- FAISS
- Sentence Transformers
- PyPDF
